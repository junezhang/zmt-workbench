# 自媒体工作台 ✨

一个免费、零代码、可装到手机桌面的自媒体个人工作台。纯静态 PWA，电脑手机都能用，数据每天早晨自动更新。

公网地址：https://junezhang.github.io/zmt-workbench/

## 它能帮你做什么

每天早晨自动联网抓取当天最火话题和真实低门槛搞钱项目，点一个话题直接生成可发公众号的爆款文章，还能记录你学技能、读书、发文章的进度。

适合想做自媒体但不想被工具拖累的人。打开就能用，不用花钱买任何服务。

## 功能模块

首页：今日最火选题 + 数据更新状态 + 连续打卡天数

选题：今日各平台热点话题，点开看事件概要和切入角度

写文案：点选题一键生成公众号爆款文章，设计师视角，古画新解，热点事件

拍摄清单：根据选题生成分镜、道具、口播、封面和发布提醒

发布记录：记下你发了什么、在哪发、数据如何

搞钱灵感：真实低门槛项目，带来源链接，不卖课

成长计划：你的阶段性目标，拆成可执行的动作

技能学习：记录在学的技能和投入时长

读书：书目和阅读进度，标记读完的

设置：导出导入本地数据，关掉某类推送

## 技术特点

纯静态前端，HTML、CSS、JavaScript，零后端，零数据库。

PWA 可安装：手机浏览器打开后「添加到主屏幕」，图标在桌面，离线也能开。

Service Worker 离线缓存：断网时显示上一次数据，不空白。

localStorage 持久化：打卡、发布记录、读书进度只存在你本机浏览器，不上传。

蓝粉渐变配色，简单可爱，多用 emoji。

## 本地运行

方式一，用启动脚本：

双击项目里的「启动.bat」，它会自动起一个本地服务器并打开浏览器。

方式二，手动起服务：

在项目目录执行下面的命令，再访问 http://localhost:8765/

    python -m http.server 8765

也可以直接双击 index.html 用文件方式打开，桌面端能用，但会少了离线缓存和装到桌面的能力。

## 部署到 GitHub Pages

本项目已部署到 GitHub Pages，地址见顶部。部署方式供参考：

仓库用 SSH 部署密钥推送，不在 remote 里写明文 token。

生成部署密钥：

    ssh-keygen -t ed25519 -C "zmt-workbench-deploy" -f ~/.ssh/id_ed25519_zmt

把公钥内容贴到仓库 Settings 的 Deploy keys，勾选 Allow write access。

本地推送：

    git add -A
    git commit -m "update"
    git push origin main

GitHub Pages 从 main 分支根目录发布，构建后一两分钟生效。

## 每日自动更新如何工作

每天早晨自动任务联网抓取当天热点和搞钱项目，写入 data/daily.js，再 push 到这个仓库。GitHub Pages 会自动更新公网内容。

你打开页面时会自动拉当日数据。想立刻看新内容，点右上角刷新按钮即可。

断网或自动任务未跑时，页面显示上一次缓存的数据，不会空白。

## 数据来源与说明

热点话题和搞钱项目来自公开平台的搜索结果，每条都标注来源链接，便于你核实。

文案由内置引擎按公众号调性生成，结构为引出热点、前因后果、设计师观点、金句总结，强调原创，不照抄参考。

辩证看两点。第一，自动抓取依赖搜索结果的质量，个别条目的热度会随时间变化，发布前建议你自己核对来源。第二，搞钱项目标注的是真实信息差和低门槛方向，收益数字来自公开案例，不构成承诺，动手前请自行判断风险。

## 隐私

所有打卡、发布、读书记录只存在你浏览器本地，不上传服务器。换设备或用无痕模式时这些记录不会同步。

需要跨设备同步，可以导出设置里的数据文件，再导入到另一台设备。

## 目录结构

index.html 入口文件

assets 样式、脚本、视图逻辑

data 每日数据 daily.js，历史备份在 data/history

icons 应用图标

manifest.webmanifest PWA 配置

sw.js Service Worker 缓存逻辑

启动.bat 本地启动脚本
